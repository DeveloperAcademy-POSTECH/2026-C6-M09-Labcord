


# 화면 캡쳐 기술검증
|항목|결과|비고|
|---|:---:|---|
|캡쳐감지|✅|화면 캡쳐시 기록이 남음|
|스크린샷마스킹|✅|특정부분에 레이어를 덧대서 캡쳐를 가릴수있음|
|녹화 중 앱실행|❌|녹화상태에서는 앱 진입이 불가함,<br> 반대로 앱내에서 녹화를 켜도 화면이 보이지않음|






## 검증방법
### [캡쳐감지] 


**준비** : 실험 상세 화면

1. 화면 캡쳐
2. 앱 화면 확인
3. 캡쳐가 감지되었습니다 문구 노출여부

**결과** : 기대와 동일

**결과** : 기대와 동일

### [스크린샷 마스킹]

**준비** : 녹음 기록이 있는 화면

1. 캡쳐버튼을 통해 화면 확인
2. 녹음 타인라인 부분이 잘 가려저서 나오는지 확인
3. 사진 앱에서 스크린샷 확인

**결과** : 기대와 동일

### [녹화중 앱실행]

**준비** : 실험 상세화면

1. 제어센터 > 화면기록버튼 > 3초후 기록시작
2. 앱 진입가능 여부 (연구중엔 녹화가 불가능해요 및 검은 마스킹 화면 노출여부)

**결과** : 기대와 동일

**반대**

1. 앱 진입
2. 제어센터 > 화면기록버튼 > 3초후 기록시작
3. 앱 화면 확인

**결과** : 기대와 동일
