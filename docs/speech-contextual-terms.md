# STT 참고어 정리

실험 세션을 열 때 `ExperimentSessionRepository`는 저장된 재료·시료·용어·단위를
`SpeechContextualTerms.prepare`로 정리해 `speechContextualStrings`에 담습니다.
화면과 음성 인식 요청은 같은 배열을 사용합니다. 프로토콜 원본·분류·R117 점수는 변경하지 않습니다.

- 한국어 이름의 단순 괄호 별칭·방식을 분리합니다. `깔때기(Funnel)`은 `깔때기`, `Funnel`,
  `온도계(전자식)`은 `온도계`, `전자식`이 됩니다. 영문 구절 내부의 공백은 유지합니다.
- 분리 후 중복을 대소문자 구분하여 제거하며 첫 출현 순서를 유지합니다. `mM`과 `mm`는 다릅니다.
- 농도, 화학식 내부 괄호, 중첩·불완전 괄호, 대안·제외 표현은 보존합니다.
  두 글자 이하의 영문 괄호는 OCR 조각·기호와 구분하기 어려워 원형을 유지합니다.
- 숫자만 든 뒤쪽 괄호는 주석으로 취급하여 사전 단어로 추가하지 않습니다.
- 영문 이름의 괄호는 화학 구조와 별칭을 구분할 근거가 부족하므로 보존합니다.
- `Compute cell constant`처럼 계산 지시어로 시작하는 짧은 어구는 `cell constant`로 정리합니다.
  단일 명사·긴 문장·조건문은 보존합니다. 일반 문장 명사구 추출기는 아닙니다.

이 처리는 선정된 용어를 STT 입력으로 정리하는 단계입니다. 선정에서 빠진 용어를 복구하거나
실제 음성 인식률 개선을 증명하지 않습니다. 사용자 검토의 `물중탕` 제외는 개발 평가 항목의
판정이며 제품 전체 금칙어로 구현하지 않았습니다.

검증 대상은 `SpeechContextualTermsTests`의 어휘 분리·보존 검사와 저장 프로토콜→세션 상세
연결 검사입니다. 실제 ASR 효과는 동일 음성과 정답 전사를 이용해 별도로 확인해야 합니다.
