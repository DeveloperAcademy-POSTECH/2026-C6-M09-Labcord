## 제작 원칙

- 사진 장면 4개와 영상 기록용 정지 이미지 2개를 만듭니다. 음성 기록은 임시 전사 문구 3개를 사용합니다.
- A01 라벨, 시험관 형태, 흰 배경, 카메라 구도와 광원을 일관되게 유지합니다.
- pH 값은 프로토콜의 합성 예시값입니다. 기기가 직접 측정하거나 Labcord가 정확성을 보증하는 장면으로 표현하지 않습니다.
- 영상 기록은 움직이는 영상을 새로 촬영하지 않고 지정된 정지 이미지 한 장을 사용합니다. 앱이 영상 파일을 요구하면 정지 이미지를 영상으로 감싸는 방식이 필요한지 구현 시 확인합니다.
- 기존 실험과 기록은 보존하며, 가상 결과를 실제 데이터인 것처럼 덮어쓰지 않습니다.

## 사진·영상 촬영 장면용 영상 프롬프트

아래 영상은 카메라 미리보기의 초록 영역에 합성할 실험실 장면입니다. 손동작과 앱 반응의 기준 프레임을 맞추기 위해 카메라 구도는 고정하고, 인물 얼굴과 로고·문구는 넣지 않습니다. 합성은 손의 위치와 촬영 UI를 가리지 않도록 합니다.

### 사진 촬영 — iPhone 제스처

**장면 프롬프트**

> 고정 카메라로 촬영한 사실적인 화학 실험실 클로즈업. 흰 실험대 위의 투명 시험관 A01에 균일한 주황색 용액이 담겨 있다. 화면 옆에서 니트릴 장갑을 낀 손이 자연스럽게 들어와 손바닥을 카메라 쪽으로 완전히 편 채 잠시 멈춘다. 이어 손가락을 천천히 접어 주먹을 확실히 쥐고, 주먹을 잠시 유지한다. 시험관과 배경은 움직이지 않고, 밝고 부드러운 실험실 조명이 유지된다. 손과 시험관이 잘 보이며 얼굴, 자막, 로고, 화면 UI는 없다. 세로 9:16, 사실적인 손가락 다섯 개, 흔들림 없는 카메라.

**트리거·편집 타이밍**

1. 손을 편 상태를 최소 2초 유지합니다.
2. 주먹이 완성되는 시점을 트리거 기준점으로 잡고 사진 단축어를 실행합니다.
3. 사진 단축어가 수락되면 5초 카운트다운 후 촬영됩니다. 촬영이 완료되면 앱의 사진 미리보기를 보여줍니다. 미리보기는 기본적으로 3초 뒤 자동 저장됩니다.
4. 촬영 화면용 영상과 결과에 들어갈 사진 이미지는 별도 자산으로 준비합니다. 이미지 합성은 실제 촬영 피사체가 같은 장면으로 이어지게 맞춥니다.

### 영상 촬영 — iPhone 제스처

**장면 프롬프트**

> 같은 흰 실험대, 같은 A01 시험관과 동일한 주황색 용액을 유지한 사실적인 화학 실험실 클로즈업. 화면 옆에서 니트릴 장갑을 낀 손이 들어와 검지·중지·약지 세 손가락을 카메라 쪽으로 명확하게 펴고, 엄지와 새끼손가락은 접은 상태로 잠시 유지한다. 제스처 후 손은 천천히 화면 밖으로 빠지고, 시험관은 고정된 구도와 조명 아래 그대로 보인다. 얼굴, 자막, 로고, 화면 UI 없이 세로 9:16, 손가락이 변형되지 않는 자연스러운 움직임.

**트리거·편집 타이밍**

1. 세 손가락이 명확하게 펴진 시점을 트리거 기준점으로 잡고 영상 단축어를 실행합니다.
2. 앱의 녹화 표시와 경과 시간을 보여주고, 앱의 기존 최대 녹화 시간에 맞춰 종료합니다.
3. 촬영 종료 후 앱의 영상 미리보기 화면을 보여줍니다. 재생이 끝나면 기본적으로 3초 뒤 자동 저장됩니다. 결과 기록에 쓸 영상은 별도로 제공받을 정지 이미지 한 장을 짧은 MOV로 만든 자산을 사용합니다.

### Watch 제스처 연출

Watch를 착용한 손을 별도로 촬영합니다. 음성은 엄지와 검지를 빠르게 두 번 모으고, 사진은 주먹 한 번, 영상은 주먹을 빠르게 두 번 쥡니다. 손동작이 완성되는 순간 iPhone 단축어를 실행하도록 컷을 맞춥니다. 이는 촬영 연출이며 실제 제스처 인식 성공을 검증한 결과는 아닙니다.

### 음성 기록 — 배경 영상

음성 기록 중에도 iPhone의 초록 미리보기 영역 뒤에 실험 장면을 합성합니다. 아래 세 영상은 동일한 실험대와 A01 시험관의 일관된 구도·조명으로 준비합니다. 화면에 보이는 행동과 음성 전사 문구가 같은 시점의 관찰을 가리키도록 맞춥니다.

**음성 1 — 혼합 직후**

> 세로 9:16의 사실적인 화학 실험실 클로즈업. 밝은 흰 실험대에 주황색 용액이 든 투명 시험관 A01과 pH 측정기가 놓여 있고 측정기는 4.04를 표시한다. 니트릴 장갑을 낀 연구자의 손이 시험관을 가볍게 살펴본 뒤 한 손가락을 카메라를 향해 명확히 펴서 잠시 유지한다. 손이 내려간 후 시험관과 측정기가 안정적으로 보인다. 고정 카메라, 부드러운 중립 조명, 자연스러운 손가락 다섯 개, 얼굴·자막·로고·앱 UI 없음.

전사: “A01, pH 4.04 확인. 지시약 두 방울을 넣고 혼합했습니다. 주황색이며 침전은 보이지 않습니다.”

**음성 2 — 5분 관찰**

> 같은 시험관 A01, 같은 흰 실험대와 조명, 같은 정면 구도의 실험실 클로즈업. 장갑 낀 손이 주황색 용액을 살펴보고 한 손가락을 카메라에 명확히 펴서 유지한 다음 천천히 내린다. 용액은 균일한 주황색이며 불필요한 물체 움직임은 없다. 세로 9:16, 고정 카메라, 사실적인 손, 얼굴·자막·로고·앱 UI 없음.

전사: “A01, 5분 경과. 색상 변화 없이 주황색을 유지하고 있습니다.”

**음성 3 — 15분 관찰**

> 같은 조명과 구도의 흰 실험대 위 A01 시험관 클로즈업. 주황색 용액과 시험관 바닥이 잘 보이고, 장갑 낀 손이 시험관 옆에서 한 손가락을 카메라에 명확히 편 상태로 잠시 유지한 뒤 내린다. 화면은 안정적으로 유지되며 시험관 안에 침전이나 기포가 두드러지지 않는다. 세로 9:16, 사실적인 실험 장면, 얼굴·자막·로고·앱 UI 없음.

전사: “A01, 15분 관찰 완료. 주황색이 유지되고 침전은 관찰되지 않았습니다.”

**트리거·편집 타이밍:** iPhone 연출은 손가락 하나를 명확히 편 순간을 기준점으로 잡습니다. Watch 연출이라면 Watch를 착용한 손의 엄지와 검지가 두 번 맞닿는 장면을 별도 컷으로 촬영하고, 두 번째 접촉 시점에 음성 기록 단축어를 실행합니다. 앱이 실제로 녹음 시작 상태를 표시한 뒤 전사를 말하고, 종료 후 실제 미리보기 화면이 보이는 길이만큼 유지합니다. 단축어 트리거와 손동작 인식 검증은 별개입니다.

### 새로 추가한 영상 프롬프트

**V01 — 도입**

> 세로 9:16, iPhone 전면 카메라가 바라보는 시점의 사실적인 화학 실험실 영상. 흰 실험대와 주황색 용액이 든 A01 투명 시험관이 배경에 고정돼 있다. 니트릴 장갑을 낀 연구자의 손이 실험대 쪽에서 카메라를 향해 자연스럽게 다가온다. 검지를 펴고 나머지 손가락은 편하게 굽힌 채 카메라 바로 앞의 보이지 않는 휴대전화 화면 하단을 향해 손가락을 이동한다. 검지 끝이 화면에 한 번 닿는 동작이 명확히 보인 뒤 손을 천천히 원래 위치로 물린다. 손가락이 렌즈를 완전히 가리지 않으며 시험관은 화면에 계속 남아 있다. 터치 전에는 손과 실험대가 2초 이상 안정적으로 보이고, 터치 후에도 3초 이상 같은 구도를 유지한다. 고정 카메라, 밝고 부드러운 중립 조명, 자연스러운 손가락 다섯 개. 휴대전화 프레임, 앱 화면, 글자, 숫자, 자막, 로고, 추가 손가락 없음.

**앱 조작과 합성 기준:** 프로토콜에서 추출한 타이머가 이미 있다면 실험 화면의 타이머 패널을 펼치고 `설정된 타이머`에서 원하는 시간 타일을 한 번 탭합니다. 코드상 타일 탭이 시작 요청이므로, V12의 검지 접촉 프레임에 그 탭을 맞춥니다. 시작된 타이머의 경과 표시는 앱 화면으로 확인합니다. 별도로 `타이머 실행` 버튼을 누르는 순서가 아닙니다. 자유 실험이거나 새 타이머가 필요하면 패널의 `+` → 시간 선택 → `타이머 실행` 순서이며, 각 터치와 스크롤은 추가 테이크로 나눕니다. 실제 화면에서 패널과 초록 영역의 경계를 확인한 뒤, 손가락 접촉 위치가 타일 위와 맞도록 합성·크롭합니다. 위 순서는 코드 기준이며 녹화 전 실제 화면 확인이 필요합니다.
