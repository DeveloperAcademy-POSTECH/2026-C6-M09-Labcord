# Labcord 녹화 시나리오

기준: 사용자가 제공한 내레이션. 아래 시간은 촬영 및 편집을 위한 **가안**이며, 실제 나레이션 합성본의 길이와 화면 반응을 확인해 다시 맞춥니다. 각 화면은 동작이 끝난 뒤 최소 2초 더 유지합니다.

| 순서 | 내레이션 | 화면과 실행 큐 | 소재 |
| --- | --- | --- | --- |
| 1 | 기록 때문에 놓치는 실험의 순간이 없도록. 두 손은 실험에, 기록은 랩코드에. | 실험대 준비 화면을 여유 있게 보여준다. | V01 |
| 2 | 홈 화면에서 더하기 버튼을 누르고 실험에 사용할 프로토콜을 선택해 주세요. | 홈의 `+` → 실험 등록 → 최근 사용한 프로토콜 또는 파일 선택. 선택된 파일명이 보일 때까지 기다린다. | iPhone 실제 화면 |
| 3 | 추출된 타이머와 용어를 확인하고 실험을 등록합니다. | 분석 완료·확인 → 결과 화면에서 타이머와 용어를 보여주고 `실험 등록`. 추출 실패나 경고가 있으면 결과를 확인한 뒤 진행한다. | iPhone 실제 화면 |
| 4 | 아이폰은 손이 잘 보이는 곳에 놓아주세요. | 거치된 휴대전화와 실험대를 보여준다. | V02 |

| 8 | 카운트다운이 끝나면 촬영한 사진을 확인할 수 있어요. | 사진 미리보기가 나타나는 것을 확인한다. 기본 자동 저장은 3초 뒤이므로 화면이 필요한 경우 그 전에 촬영한다. | iPhone 실제 화면 |
| 9 | 손가락 세 개를 펴면 영상 녹화가 시작됩니다. | V05를 재생하면 기준 프레임에 영상 녹화를 요청한다. 녹화 상태를 확인한다. | V05 + iPhone 초록 화면 |

| 14 | 사진과 영상은 연결된 아이폰으로 촬영돼요. | 사진·영상 촬영 반응과 미리보기를 보여준다. | iPhone 실제 화면 |

## 녹화 전 확인

- `record` 촬영용 Debug 시뮬레이터에서 카메라 미리보기는 V03·V04·V05·V06-A·V07·V08·V12를 재생할 수 있다. 손동작 인식은 사용하지 않는다. 사진은 촬영 시점의 프레임이며 영상 기록은 촬영 시작 시점부터의 배경 영상이다. 배경 영상이 먼저 끝나면 마지막 프레임을 유지한다.
- 이번에는 Watch 화면을 녹화하지 않는다. Watch 제스처 장면은 iPhone의 기록 화면으로 연출하며 실제 기기 간 동작 검증이 아니다.
- Debug 시뮬레이터에서 마이크 권한이 허용되어 있어도 녹음 장치를 시작할 수 없으면 영상은 무음으로 생성한다. 마이크 권한이 거부된 경우에는 권한 오류를 표시한다.
- 이미 결정된 시스템 권한은 앱을 다시 열어도 팝업으로 반복 요청되지 않는다. 접근이 거부된 경우 사용자가 설정에서 확인한다.
- 합성 실험 결과를 위해 사진 4장, 영상용 정지 이미지 2장, 음성 3개가 필요하다. 파일 대응표는 [가져오기 안내](recording-demo-import.md)를 참고한다. 실행 시 촬영용 시뮬레이터의 기존 실험과 관련 미디어가 삭제된다.
- V06-A·V07·V08의 iPhone 기록 실행, 저장과 프레임 지연은 실제 촬영 전에 별도 확인한다.
