# 실험 기록 조회와 타이머 편집

- 홈의 **최근 실험**(준비·완료 항목)은 저장된 실험 기록을 연다. 조회만으로 촬영을 시작하거나 완료 상태를 변경하지 않는다.
- **진행 중인 실험**은 기존 촬영/기록 세션을 재개한다.
- 기록 화면의 **실험 재개**를 눌러야 촬영/기록 세션으로 이동한다. 이전 종료 시각과 기록은 보존하며 재개 이력을 추가한다.
- **홈으로 이동** 또는 상단 뒤로 가기는 홈 목록을 다시 불러온다.

## 기록 화면

사진, 영상, 음성 전사·재생, 타이머 설정·종료·일시정지 및 실험 상태 이력을 날짜별로 표시한다.
유형 필터는 실제 저장된 기록에 적용하고 전체 보기에서는 상태 이력도 표시한다.
오래된순/최신순은 날짜와 기록 시각 순서에 적용한다.

미디어는 Application Support의 저장된 상대 경로를 사용한다. 파일이 없거나 미리보기·음성 재생에
실패하면 해당 상태를 표시하고 기록 자체는 제거하지 않는다. 음성은 공통 VoicePlayer, 사진·영상·
타이머 행은 TimelineItem, 실험 상태는 TimelineExperimentState를 사용한다.
영상은 시스템 플레이어에서 재생한다. 화면 종료·앱 비활성화 시 재생을 중단한다.

이번 범위는 조회와 명시적 재개다. 아직 연결되지 않은 기록 편집 버튼은 표시하지 않는다.
메모/전사 편집·기록 삭제·내보내기·사진 확대는 추가하지 않았다. 미디어·저장 스키마는 변경하지 않았다.
타이머 식별색은 저장 모델에 없으므로 임의 색을 기록에 부여하지 않는다.

## 등록 화면의 타이머 편집

편집 시트 항목에 해당 타이머의 Duration을 담아 시트별 초깃값으로 사용한다.
다른 타이머를 열면 그 타이머 값으로 초기화하고, 닫기·스와이프 취소는 저장값을 바꾸지 않는다.
새 타이머는 0초로 시작하며 저장/삭제는 기존 Feature 액션을 사용한다.
