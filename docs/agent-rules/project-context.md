# Agent Rules·Skills 프로젝트 맥락

현재 의존성은 [Package.resolved](../../Researchers.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved),
모듈 구성은 [Package.swift](../../Packages/ResearchersModules/Package.swift)를 확인합니다.

## 현재 구현과 적용 기준

| 항목 | 현재 설정·적용 |
| --- | --- |
| Watch 앱 경로 | 소스는 `ResearchWatchApp/`, 스킴은 `ResearchWatch Watch App` |
| 로컬 패키지 | 단일 `Packages/ResearchersModules/Package.swift` 아래 네 개 타깃 |
| 기기별 저장·통신 | 기기별 구현은 `LabcordiOS`·`LabcordWatchOS`에도 있음. 새 저장 구현의 경로는 해당 작업에서 팀과 확인 |
| SwiftData | `LabcordShared/Models`의 모델 선언과 iPhone의 저장 실행 책임을 구분. Watch에 저장 구현을 새로 두거나 기존 모델을 자동 이동하지 않음 |
| iPhone·Watch 화면 | iPhone 실행과 Debug 데이터 초기화마다 새 epoch를 발행하고, 목록·화면·실험·기록의 revision은 해당 epoch 안에서 비교. Watch의 화면 이동은 iPhone의 현재 화면 버전을 확인한 뒤 반영하며 녹음·저장 미확정·편집 초안은 보호 |
| Watch 실험 시작·결과 | Watch 시작 요청은 20초 동안 유효. iPhone은 저장 직전 취소·만료를 확인하고, 진입을 저장한 뒤 요청 ID로 응답. 준비 중 해당 요청을 취소하면 기존 실험 이력을 보존. 결과 화면이 사라지면 Watch에서 닫거나 iPhone 화면을 다시 조회할 수 있음 |
| Watch 실험 목록 | 조회된 목록을 화면에 바로 반영하고 이전 세대의 응답을 무시합니다. 전송한 시작 요청은 Watch 화면이 일시 비활성화되어도 진행합니다. Watch에서 진행 중인 실험에 진입하면 iPhone도 해당 실험을 엽니다. |
| Watch 기록 화면과 타이머 | 기록 화면 제목은 한 줄로 표시하고 길면 끝을 줄임표로 표시합니다. Watch에서 목록으로 돌아갈 때 이전 iPhone 화면으로 인한 자동 재진입을 차단합니다. 타이머 목록에서 스와이프 삭제 버튼은 일시정지한 한 행씩 열리고, 제스처가 취소되면 임시 이동값을 초기화합니다. |
| Watch 실험 타이머 정보 | Watch 실험 화면은 해당 실험의 `WatchExperimentSnapshot`을 요청·구독하고, `mode`를 타이머 페이지에 표시. 프로토콜 타이머 시간과 진행 중인 타이머 배열도 snapshot에 포함 |
| 타이머 Live Activity | 세션에서 홈으로 나가면 실행 중인 타이머를 동기화. iPhone·Watch에서 실험 종료를 저장하면 같은 실험의 앞선 동기화가 끝난 뒤 타이머 Activity를 모두 종료 |
| iPhone 사진 촬영 | 버튼과 제스처는 같은 카메라 경로로 촬영합니다. 영상 준비용 마이크가 활성화된 상태에서는 사진 촬영 동안 시스템 셔터음을 허용한 뒤 기존 오디오 설정을 복원합니다. iPhone은 Watch에서 찍은 사진도 실제 3초 마감에 한 번만 저장합니다. |
| iPhone 영상 제스처 | 세 손가락 제스처로 녹화를 시작합니다. 5초 녹화가 끝나기 전에 같은 제스처를 다시 인식하면 정지합니다. 시작 처리 중에 인식한 정지는 녹화가 시작되는 즉시 적용합니다. |
| Watch 녹음 표시 | iPhone 앱 상단에 기존 녹음 카드로 Apple Watch 녹음 상태를 표시. 녹음이 끝나거나 마지막 상태의 유효 시간이 지나면 숨기고 iPhone의 녹음·녹화 카드가 우선 |
| Watch 녹음 오디오 | 새 Watch 녹음은 16 kHz 모노 signed 16-bit little-endian PCM으로 변환해 v1 형식으로 보관·전송. iPhone은 녹음 헤더의 샘플레이트로 저장·재생하고, 전사 입력은 기기의 SpeechAnalyzer와 언어 모델이 지원하는 포맷에 맞춤 |
| Watch 연결 복구 | 세션 활성화·설치 인식·도달 가능성을 구분해 기록합니다. 복구 시 현재 화면·실험·목록과 현재 실험 기록을 다시 게시합니다. 백그라운드 전송의 큐·완료·실패는 전송 ID로 연결하며, 완료 콜백은 iPhone 저장 확인과 별개입니다. |
| Watch 복구 저장소 | 기존 `requests.json`을 읽고 새 저널 변경은 요청별 원자적 파일에 기록합니다. 오디오 청크의 검증된 샘플 범위만 메모리에 재사용하며, 정리와 저장 증명은 디스크의 원본을 검증합니다. |
| 기록 표시와 저장 | 상대 기기의 화면 표시는 원본 처리에 사용하지 않음. Watch 녹음 화면을 닫아도 원본을 보존하며 다시 열면 같은 ID로 전송·저장을 재개. iPhone에 저장한 PCM과 일치하는 응답이나 명시적 취소 확정까지 해당 실험의 나가기·종료를 보류. Watch 원본 정리는 저장 파일 검증을 거친 뒤 진행하며, 종료된 기록의 표시 시간은 고정 |
| Watch 사진·영상 명령 | iPhone은 실험·기록 ID·종류·revision과 중복을 확인한 뒤 실행합니다. 화면의 명령 완료 대기는 10초이고, 만료돼도 처리 중이거나 저장 대상인 원본은 그대로 둡니다. Watch는 미확정 기록의 ID를 보관해 재연결·재실행 때 조회합니다. 저장된 기록의 취소 요청은 저장 상태와 취소 거부를 함께 반환합니다. |
| 들여쓰기 | 스타일 가이드는 2 spaces, 기존 Swift는 주로 4 spaces. 적용 기준은 팀 확인 사항이며 일괄 포맷 변경하지 않음 |
| import 배치 | 스타일 가이드와 기존 코드 배치에 차이가 있음. `.swiftlint.yml`의 `sorted_imports`도 확인하며 새 우선순위를 임의 확정하지 않음 |
| 줄 길이 | warning 99·error 150이고 `--strict`는 warning도 실패 처리 |
| 도구·SDK | Package의 iOS/watchOS 최소 26, 프로젝트 배포 대상 27.0, CI runner `xcode-27`, Swift tools 6.4 |
| TCA API | 잠긴 버전은 1.26.2. 사용하는 API의 지원 여부를 확인 |
| 제스처 연습 애니메이션 | iPhone 앱이 Lottie 4.6.1로 Watch 제스처 JSON을 재생. iPhone 제스처 세 개를 완료하면 같은 화면의 Apple Watch 연습 탭으로 이동합니다. iPhone의 Watch 연습 탭에서 받은 단축어는 해당 카드의 인식 결과만 표시합니다. Watch 앱을 처음 열 때는 제스처 전에 열려 있던 iPhone 실험을 최대 3초 동안 확인합니다. 같은 실험 안에서 타이머나 기록 상태가 바뀌어도 요청을 이어가며, 실험에서 나갔다가 다시 들어오면 이전 요청은 만료됩니다. |
| 최초 홈 제스처 안내 | 온보딩을 마친 신규 사용자는 연습 화면이 준비될 때까지 물음표 안내로 진입 |
| 실험 권한·설정 복귀 | 권한 확인과 alert 문구, 설정 복귀 ID 저장은 `LabcordiOS/Permissions`가 담당. iPhone 화면 복귀 경로와 준비 overlay는 `Researchers`가 담당 |
| 음성 인식 용어 힌트 | iPhone과 Watch 녹음 전사에 프로토콜 추출 용어, 단위 힌트, 공통 연구 용어를 우선순위 순으로 합쳐 중복을 제거하고 최대 100개를 전달. 별도 사용자 지정 언어 모델의 가중치는 0.3 |
| 프로토콜 분석 결과 용어 | 카테고리별 수동 추가는 20개 미만일 때 가능. 이미 20개 이상인 분석·기존 결과는 보존하고 삭제해 20개 미만이 되면 다시 추가 가능 |
| 프로토콜 분석 중단 | 미완료 결과 화면에 부분 결과와 등록 시 분석 종료를 안내. 뒤로 가면 화면의 편집은 버리고 분석 화면에서 재시도 가능. 실행 오류는 문서 내용 없이 오류 도메인·코드와 진행 단계를 기록 |

현재 경로·버전·설정 등 확인 가능한 사실은 실제 저장소와 일치하도록 유지합니다.
기존 팀 규칙과 충돌하는 동작이나 새 정책의 결정이 필요하면 팀에 확인합니다.
단순한 경로·버전 갱신을 위해 별도 승인을 반복해서 요청하지 않습니다.
