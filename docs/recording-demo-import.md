# 시뮬레이터 녹화용 결과 가져오기

시뮬레이터 Debug 앱의 숨겨진 `시연 결과 준비` 접근성 버튼을 실행하면 합성 실험 결과를 추가합니다. 앱 실행 직후에는 추가하지 않습니다.
실제 기기에는 동작하지 않습니다. 이 브랜치의 Debug 시뮬레이터 앱은 기본 실행 시 기존 실험과 관련 미디어를 삭제합니다. 기존 촬영 데이터를 유지할 때는 먼저 별도로 백업하고 `-LabcordPreserveSimulatorExperiments` 실행 인수로 시작합니다. 이 인수가 있으면 시작 시 실험 초기화를 건너뜁니다.

## 입력 파일

앱이 읽을 수 있는 같은 폴더에 다음 파일을 준비합니다.

- `photo-1.jpg` ~ `photo-4.jpg`: 장면 목록의 사진 네 장
- `audio-1.caf` ~ `audio-3.caf`: 장면 목록의 음성 세 개
- `video-1.jpg` ~ `video-2.jpg`: 영상 장면마다 사용할 정지 이미지 한 장

| 파일 | 장면 |
| --- | --- |
| `photo-1.jpg` | A01~C03 시료 아홉 개 배치 |
| `photo-2.jpg` | A01 혼합 직후 |
| `photo-3.jpg` | A01 5분 관찰 |
| `photo-4.jpg` | A01·B01·C01 세 색상 비교 |
| `audio-1.caf` | A01 pH 4.04 및 혼합 직후 관찰 |
| `audio-2.caf` | A01 5분 관찰 |
| `audio-3.caf` | A01 15분 관찰 |
| `video-1.jpg` | A01 지시약 첨가·혼합 장면 |
| `video-2.jpg` | A01 15분 종료 관찰 |

V01~V12 배경 영상은 결과 기록 입력이 아닙니다. iPhone 시뮬레이터의 카메라 영역에서
V03·V04·V05·V06-A·V07·V08·V12를 재생할 수 있으며 각 영상의 지정 시점에 기록 또는 타이머 동작을
요청합니다. 이는 영상 속 손동작 인식이 아니며 실제 화면 반응 지연은 별도 확인합니다.
V06-A를 선택하면 `W02_double_pinch.mp4`가 재생되어 Watch 두 번 핀치 뒤 발화 장면이 이어집니다.
파일이 없으면 V06-A 버튼은 비활성화되며, 이전 `V06-A.mp4`와 합본은 별도로 보존합니다.
Watch 음성 장면은 녹음 중 전사 문장을 표시하지 않고, 종료 후 두 번째 대본 두 문장을 최종 전사로 표시합니다.
`V07`은 `W03_single_fist.mp4`의 주먹 기준 28프레임에 사진 촬영을 요청하고,
`V08`은 `W04_double_fist.mp4`의 두 번째 주먹 기준 35프레임에 영상 녹화를 요청합니다.
`W01_ready`·`W05_phone_capture`는 기록 요청 없이 재생만 하는 준비·마무리 컷입니다.
실행 조건과 검증 상태는 [녹화 진행 큐](recording-cues.md)를 참고합니다.

장면과 문구는 [가상 실험 장면 목록](recording-demo-scenes.md)을 참조합니다. 사진은 실제로 읽을 수 있는 JPEG여야 하고, 음성은 재생 가능한 오디오 트랙과 0보다 긴 길이가 있어야 합니다. 하나라도 빠지거나 유효하지 않으면 실험을 만들기 전에 중단합니다. 영상 기록에는 사진 한 장을 3초짜리 무음 MOV로 변환해 저장합니다.

## 가져오기

Debug 시뮬레이터 실행 인수에 다음 두 항목을 추가하고 실행합니다.

```text
-LabcordDemoSeedDirectory
<앱에서 읽을 수 있는 입력 폴더의 절대 경로>
```

인수를 지정하지 않더라도 앱 Documents의 `LabcordDemoInput` 폴더가 존재하면 그 폴더를 사용합니다. 입력 폴더를 준비한 뒤 홈에서 자동화 도구로 접근성 버튼 `시연 결과 준비`를 누릅니다. 완료되면 `시연 결과 준비 완료`로 바뀌고, 실패하면 화면과 콘솔에 사유를 표시합니다. 가져온 결과는 제목 `Labcord`인 별도 완료 실험이며 기록 내용은 촬영용 합성 예시입니다.

보존 인수 없이 앱을 실행하면 먼저 실험 목록을 읽고 실험별 데이터 및 미디어를 삭제한 다음, 남은 `Photos`, `Videos`, `Audio`, `VoiceRecordingJournals`, `IncompleteVoiceRecordings`, `WatchAudioIncoming`, `WatchAudioInbox` 폴더를 삭제합니다. 그다음 Watch 연결을 시작하고 지정된 경우 시연 결과를 가져옵니다. 이 과정은 되돌릴 수 없으며, 실패 시 일부 데이터가 이미 삭제되었을 수 있습니다. 초기화 실패 시 앱은 오류를 표시하고 정상 화면과 Watch 연결을 시작하지 않습니다. 다른 파일, 원본 입력 파일, 권한 및 최근 파일 앱의 PDF는 초기화 대상이 아닙니다.

시연 가져오기 도중 오류가 발생하면 이미 저장된 시연 기록은 그 실행 중에 남습니다. 보존 인수 없이 앱을 다시 실행하면 초기화하며, 결과는 버튼을 다시 눌렀을 때 가져옵니다. MOV는 임시로 생성하므로 입력 사진은 이동하지 않습니다.
