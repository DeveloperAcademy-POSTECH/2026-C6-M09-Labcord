진행 중인 실험의 사진 준비에는 iPhone 마이크 권한을 요구하지 않는다. 새 실험 시작·재개는
기존 마이크 권한 조건을 유지하며, 영상 촬영은 실제 CameraSession에서 마이크 권한을 다시 검사한다.

취소 의도는 명령의 terminal 응답과 별개로 보관하고 실제 기록의 saved/cancelled에서 정리한다.
취소 실패 후 원 촬영 결과를 조회하더라도 늦은 review로 자동 저장을 재개하지 않는다.
새 시작·촬영을 자동 재실행하지 않으며, 결과 unknown인 취소만 같은 ID로 명시 재전송한다.

## 실제로 남은 조건

- C5는 사용자의 추가 승인으로 구현 선행 조건이 해제됐다. 공식 App Shortcuts 기반 세 Intent,
  단일 Store 실행 경로, 제스처 연습·실험·그 외 상태 분기를 구현했다. 직접 AssistiveTouch
  선택기 노출·배정은 남은 실기기 검증이다.
- 연결된 Watch·실기기가 없어 페어링 전송, 앱 재실행, 화면 비활성 녹음, 권한·잠금,
  카메라, Speech·다언어 품질·지연, 실제 Watch UI/Figma 렌더는 미검증이다.
- 제품 보존 기간·처리 대기 상한·지연 목표는 별도 결정 사항이다. 현재는 원본을 자동 삭제하지 않고
  기존 방어 상한과 오류·원본 보존 동작을 유지한다. 새 삭제/마이그레이션 정책을 만들지 않았다.
- PR 분할은 실제 diff·commit packet으로 검토했고 사용자가 정식 하위 이슈 추가와 기능별
  PR 분리를 승인했다. 공식 하위 이슈 #218~#241을 생성·연결했다. 기존 canonical 브랜치는 보존하고
  각 review head를 검증한 뒤 Draft로 게시한다.

미저장 사진 RAM·영상 임시 파일의 강제 종료 후 자동 복구는 원문에서 명시 요구로 확인되지 않았다.
이를 새 영속 미디어 프레임워크 요구로 확대하지 않았다. 범위 내 필수인 저장된 결과의 ACK 유실·
재실행 후 재조회와 앱 수명 내 저장 재시도는 위 코드에 반영했다.

상세 검증·실패·미실행은 [통합 검증](integrated-validation.md)을 참고한다.
전체 이슈를 close하거나 구현·검증이 모두 완료됐다고 표시하지 않았다.
