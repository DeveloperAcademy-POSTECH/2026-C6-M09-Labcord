# Watch 음성 시작·중단 경합 검사

저장소 루트에서 `sh scripts/watch-174/race/check.sh`를 실행한다. macOS의 Swift 컴파일러가 필요하다.
스크립트는 임시 디렉터리에만 모듈과 실행 파일을 만들고 종료 시 정리한다.

실제 `WatchRecordingUIBridge+Live.swift`를 직접 컴파일한다. 가짜 녹음기·보관·전송 의존성으로 시작과
취소의 순서를 제어해 초기 복구 대기 중 취소, 녹음 시작 중 취소, 취소 ACK 대기 및 실패, 취소 뒤
늦은 시작을 검사한다. 녹음기 해제 후 중지 작업이 끝나기 전 취소와 이미 저장된 기록의 보존도 확인한다.
다른 실험과 해당 기록의 가짜 보관 항목도 대조한다.

이 검사는 서비스의 제어 흐름을 확인한다. 가짜 의존성을 사용하므로 실제 음성 캡처, 파일 보존,
WatchConnectivity 전송·ACK, TCA 상위 중단 처리, 앱 재시작 및 실기기 동작은 검증하지 않는다.
