# LabCord

**실험 중 기록이 번거로운 연구자를 위한 iPhone·Apple Watch 실험 기록 앱**

음성, 사진, 영상으로 실험 과정을 빠르게 기록하고, 실험이 끝난 후 기록을 확인하고 정리할 수 있어요.

---

## Problem & Solution

실험 중 양손이 바쁜 연구자는 관찰 내용이나 돌발 상황을 즉시 기록하기 어려워요.  
LabCord는 제스처 한 번으로 음성 녹음, 사진 촬영, 영상 녹화를 실행해 실험을 방해하지 않고 기록할 수 있도록 도와줘요.  
Apple Watch에서도 빠르게 기록하고, 실험 후 iPhone에서 내용을 확인하고 정리할 수 있어요.

---

## Feature

### 실험을 방해하지 않고 말과 장면을 함께 담는 기록

손이 바쁜 순간에도 수치와 생각은 음성으로, 눈에 보이는 변화는 사진과 영상으로 남겨줘요.

### 실험에 최적화된 기록 도구

실험 전문용어와 다양한 타이머를 활용해 정확하고 편리하게 기록해요.

### 맥락을 유지하는 실험 기록

기록을 실험 및 시간 정보와 연결해 실험 후에도 맥락을 파악하고 수정할 수 있어요.

## 실행 및 시뮬레이터

iPhone 앱을 시작하면 마이크, 카메라, 음성 인식, 알림 권한을 순서대로 요청해요.
Watch 앱은 시작할 때 마이크 권한을 요청해요. 이미 선택한 권한은 시스템 설정을 따르며,
거부한 권한을 변경하려면 설정에서 직접 허용해야 해요.

iPhone 시뮬레이터는 카메라 대신 초록 화면 또는 촬영용 영상을 표시해요. Debug 촬영용 영상이 재생 중이면 사진에는 촬영 순간의 영상 프레임이 저장되고, 영상 기록은 초록 화면으로 저장돼요.
시뮬레이터의 카메라 손동작 인식과 실제 카메라 촬영은 검증할 수 없어요.
Debug 시뮬레이터의 iPhone 음성 기록은 마이크 소리를 녹음하면서 시연 문구를 순서대로 표시해요.
마이크를 시작할 수 없으면 준비된 시연 음성 파일로 대체해요. 미리보기 영상 준비 중에는 캐릭터 정지 화면을 표시해요.
표시된 문구는 실제 음성 인식 결과가 아니며 실기기 동작에는 적용되지 않아요.
