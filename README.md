# LabCord

**실험 중 기록이 번거로운 연구자를 위한 iPhone·Apple Watch 실험 기록 앱**

음성, 사진, 영상으로 실험 과정을 빠르게 기록하고, 실험이 끝난 후 기록을 확인하고 정리할 수 있어요.

---

## Problem & Solution

실험 중 양손이 바쁜 연구자는 관찰 내용이나 돌발 상황을 즉시 기록하기 어려워요.  
LabCord는 제스처 한 번으로 음성 녹음, 사진 촬영, 영상 녹화를 실행해 실험을 방해하지 않고 기록할 수 있도록 도와줘요.  
Apple Watch에서도 빠르게 기록하고, 실험 후 iPhone에서 내용을 확인하고 정리할 수 있어요.

---

## Feature

### 실험을 방해하지 않고 말과 장면을 함께 담는 기록

손이 바쁜 순간에도 수치와 생각은 음성으로, 눈에 보이는 변화는 사진과 영상으로 남겨줘요.

### 실험에 최적화된 기록 도구

실험 전문용어와 다양한 타이머를 활용해 정확하고 편리하게 기록해요.

### 맥락을 유지하는 실험 기록

기록을 실험 및 시간 정보와 연결해 실험 후에도 맥락을 파악하고 수정할 수 있어요.

## 디버깅 메뉴

Debug 빌드의 iPhone 앱 화면에서 세 손가락으로 1초 안에 세 번 탭하면 열립니다.

- **앱 초기화**를 확인하면 로컬 실험, 기록, 앱의 온보딩 진행 상태를 삭제합니다. 메뉴에서 **뒤로**를 누르면 첫 온보딩 화면이 표시됩니다. 실험 삭제 후 일부 파일 정리에 실패하면 경고를 표시합니다. iOS가 관리하는 권한은 기기 설정에서 관리합니다.
- **데모용 실험 결과 표시**는 기본으로 꺼져 있습니다. 켜면 완료된 데모 실험 4개가 최근 실험에 추가됩니다. 끄면 iPhone 목록에서 데모 실험을 숨깁니다. 저장한 기록은 다시 켜면 확인할 수 있습니다. 진행 중인 데모나 기록 편집을 마친 뒤 끌 수 있습니다. 앱을 다시 열면 기존 데모 기록은 유지됩니다. 앱 초기화 후에도 이 토글 선택은 유지됩니다.
- 데모는 토양 및 폐기물 pH 측정, 황산염 탁도 분석, 인 비색 분석, 스핀코터 공정입니다. 각 실험에는 Labcord로 분석한 프로토콜과 사진 5장, 영상 2개, 음성 3개가 포함됩니다.
- 메뉴가 열려 있는 동안 보류된 실험 열기 요청은 메뉴를 닫으면 다시 처리합니다. 유효한 Watch 시작 요청을 우선하고, Watch 요청이 무효라면 보류된 Live Activity 요청을 처리합니다. 실험 DB 삭제를 저장하지 못하면 기존 Watch 요청을 보존합니다.
