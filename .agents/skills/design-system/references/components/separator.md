# Separator

[구현](../../../../../Packages/ResearchersModules/Sources/LabcordDesignSystem/Components/Separator/LabcordSeparator.swift)

가로 구분선은 부모가 제안한 너비를 사용합니다.

```swift
LabcordSeparator()
```

- 세로 구분선은 `LabcordSeparator(orientation: .vertical)`을 사용하고 부모 또는 구분선에 높이를 정합니다.
- 구분선은 장식이며 접근성에서 숨겨집니다. 자체 선택·탭 동작은 제공하지 않습니다.
