# File Type Icon

파일 형식을 Figma의 원본 아이콘으로 표시합니다.

```swift
FileTypeIcon(.pdf)
```

- `Kind`는 `csv`, `pdf`, `docx`, `xls`를 지원합니다. 파일의 형식 판별은 호출부가 처리합니다.
- 파일 업로드나 파일 열기는 수행하지 않습니다.
