# 실제 스캔 PDF 부하 검증 원본

Credit: U.S. Geological Survey, Department of the Interior.

- `usgs-pp158.pdf`: 1930년 USGS Professional Paper 158. **원본 204쪽, 31,644,622바이트**.
- `usgs-wsp158.pdf`: 1906년 USGS Water Supply Paper 158. **원본 42쪽, 2,046,636바이트**.
- 출판 정보·다운로드 주소·SHA-256·권리 근거는 `Manifest.json`에 보관한다.
- 두 PDF는 다운로드 원본 그대로이며 기존 OCR 텍스트 층이 있다. 주 문서는 Adobe Paper Capture로 생성된 스캔이다.
- 42쪽 래스터 전용 검증 입력은 테스트 중 보조 원본 전체를 1224×1584 크기의 썸네일로 렌더링하여 만든 파생본이다. 텍스트 층이 없는지 별도로 확인한다. 새로운 가상 문서를 반복한 샘플이 아니다.
- 원본 출판물의 페이지 표기(173쪽·29쪽)는 PDF의 표지·도판·목차 등을 포함한 물리적 페이지 수와 다르다.

## 이용 조건

[USGS 권리 안내](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits)에 따라 USGS가 작성·제작한 정보는 미국 public domain이다. USGS는 출처 표시를 요청한다. 제삼자 저작물은 이 정책의 예외이므로 다른 USGS 자료까지 일괄 확대 적용하지 않는다. 이 테스트 자산 때문에 앱 소스를 공개할 의무는 없다. USGS 로고를 앱 브랜드에 사용하는 허가는 포함되지 않는다.

원본은 테스트 번들에만 복사하며 앱에 포함하지 않는다. 테스트·앱은 이 파일이나 외부 이미지를 자동 다운로드하지 않는다. 기존 20형식×3개 회귀 코퍼스와 별도의 확장 부하 자산으로 관리한다.

## 한국어 실제 스캔 원본

- `korean-1992.pdf`: 국립국어연구원, 1992, 「가나다 전화 자료집」. **125쪽·3,857,838바이트**.
- 공식 상세 페이지: https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=207&report_seq=94
- 개별 자료에 **공공누리 제1유형: 출처표시**가 명시되어 있다. 기관명·문서명·발행연도·원문 주소를 함께 표시한다.
- 출처표시 조건에서 상업적 이용·변형이 가능하다. 이 테스트 자산 때문에 앱 소스를 공개할 의무는 없다.
- 별도 AI 학습용 유형으로 이용하는 것이 아니며 모델 학습·업로드를 수행하지 않는다.
- 원본 전체를 변경 없이 보관한다. PDFKit으로 125쪽 전체의 텍스트가 비어 있음을 확인했다.
- 4·11·60·125쪽을 직접 읽어 12개 OCR 기준 문구를 골랐다. 스캔 표는 OCR 텍스트만 확인하며 셀 복원은 요구하지 않는다.
